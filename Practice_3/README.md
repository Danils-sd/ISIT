<h2>Практика №3</h2>
<i>Классификация самолётов (военный / гражданский) с помощью vision-LLM и сравнение метрик двух моделей</i>

<p>Цель: решить задачу бинарной классификации изображений самолётов («военный» / «гражданский») с помощью двух больших мультимодальных моделей, доступных через облачные провайдеры (Groq и Cloudflare Workers AI), и сравнить качество их работы по стандартным метрикам классификации.</p>

## 1. Описание проекта

Проект реализует пайплайн сравнения двух vision-LLM в задаче классификации самолётов по фотографии:

1. **Датасет** — две папки `dataset/civil/` и `dataset/military/` с изображениями. Подобраны **нетривиальные случаи** (неоднозначные ракурсы, необычные ливреи, прототипы, учебные самолёты).
2. **Модели:**
   * `Qwen3.8-27B` через **Groq** (OpenAI-совместимый API);
   * `Llama-3.2-11b-vision-instruct` через **Cloudflare Workers AI** (эндпоинт `/ai/run`).
3. **Промпт** — жёстко ограничивает ответ одним словом: `'военный'` или `'гражданский'`.
4. **Метрики** — accuracy, precision / recall / F1 по положительному классу `military`, матрица ошибок.
5. **Артефакты** — `results/predictions.csv` (сырые ответы + нормализованные метки) и `results/metrics.csv` (сводная таблица сравнения).

Реализован **полный офлайн-повторный анализ**: если `predictions.csv` уже есть, метрики можно пересчитать без обращения к API.
