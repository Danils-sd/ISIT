# ISIT

Приложение последовательно задаёт вопросы из анкеты и с помощью метода k ближайших соседей определяет тип телефона пользователя.

## Запуск

Из корня проекта:

```text
python app.py
```

Проверка данных и качества модели выполняется отдельно:

```text
python quality_check.py
python -m unittest discover -s tests -v
```

`K` находится в `config.py`. Для текущего датасета установлено `K = 7` по результатам стратифицированной кросс-валидации.

В приложении показываются только вопросы, для которых есть признаки в `data/dataset_normalized.csv`. Вопрос о ближайшей станции метро пока пропущен: в нормализованном датасете нет соответствующего столбца. Целевой столбец `phone` не показывается пользователю и кодируется так: `0` — iPhone, `1` — Android.

Для работы интерфейса нужен Python с Tkinter. Jupyter можно использовать в Rider для анализа CSV и построения дополнительных графиков; пользовательское приложение запускается обычным файлом `app.py`.
