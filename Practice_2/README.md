## 1. Описание проекта

Проект реализует комплексный сетевой анализ социального окружения студентов учебной группы в социальной сети **«ВКонтакте» (VK)** на основе алгоритмов теории сложных сетей и методов сетевого анализа (SNA — Social Network Analysis).

В соответствии с заданием №2 курса «Интеллектуальные системы и технологии» (преподаватель Судаков В.А.):
1. Для участников бригады построена **эго-сеть 2-го порядка (2-hop ego-network)**:
   * **Уровень 0:** члены учебной группы;
   * **Уровень 1:** непосредственные друзья членов группы;
   * **Уровень 2:** друзья друзей.
2. Для каждого участника бригады рассчитаны три фундаментальные метрики центральности:
   * **Центральность по посредничеству (Betweenness Centrality)**;
   * **Центральность по близости (Closeness Centrality)**;
   * **Центральность по собственному вектору (Eigenvector Centrality)**;
   * А также степень вершины (**Degree Centrality**).
3. Произведена визуализация графа с выделением уровней удаленности цветом и динамическим масштабированием размеров узлов в зависимости от посреднической силы.

Программный комплекс поддерживает как **онлайн-сбор свежих данных** через официальное VK API, так и **полнофункциональный офлайн-режим** на предварительно закэшированном графе (`data/graph.pkl`), что гарантирует моментальный запуск и полную воспроизводимость результатов без обращения к сети.

## 3. Сбор данных и топология графа

Сбор данных осуществлен через открытые методы VK API (`friends.get`, `utils.resolveScreenName`):
* **Ограничение частоты (Rate Limiting):** не более 5 запросов/сек во избежание блокировки;
* **Срез выборки (Sampling):** для каждого пользователя отбиралось не более 30 друзей (`MAX_FRIENDS_PER_USER = 30`), что предотвратило комбинаторный взрыв размерности эго-сети и позволило сформировать репрезентативный связный срез;
* **Обработка приватности:** закрытые страницы и заблокированные пользователи безопасно обрабатываются без падения программы.

### Характеристики сформированного графа:
* **Количество узлов (пользователей):** `1988`
* **Количество рёбер (связей):** `2169`
* **Компоненты связности:** `1` (граф полностью связен)
* **Плотность (Density):** $\rho = 0.001098$ (типичная разреженная социальная сеть)
* **Уровни узлов:**
  * Уровень 0 (исходная группа): 5 участников;
  * Уровень 1 (непосредственные друзья): 146 пользователей;
  * Уровень 2 (друзья друзей): 1838 пользователей.

## 4. Математический аппарат метрик центральности

### 1. Центральность по посредничеству (Betweenness Centrality)
Измеряет долю кратчайших путей между всеми парами вершин графа, проходящих через данный узел:
$$C_B(v) = \sum_{s \ne v \ne t \in V} \frac{\sigma_{st}(v)}{\sigma_{st}}$$
Нормализованное значение:
$$C'_B(v) = \frac{2}{(|V| - 1)(|V| - 2)} \sum_{s \ne v \ne t \in V} \frac{\sigma_{st}(v)}{\sigma_{st}}$$
Для вычисления используется **алгоритм Брандеса (Brandes Algorithm)** сложности $O(V \cdot E)$.

### 2. Центральность по близости (Closeness Centrality)
Характеризует среднюю скорость передачи информации от вершины до всех остальных узлов сети:
$$C_C(v) = \frac{|V| - 1}{\sum_{u \in V \setminus \{v\}} d(v, u)}$$
где $d(v, u)$ — геодезическое расстояние (длина кратчайшего пути) между $v$ и $u$.

### 3. Центральность по собственному вектору (Eigenvector Centrality)
Определяет важность узла с учётом влиятельности его непосредственных соседей:
$$\lambda x_i = \sum_{j=1}^{n} A_{ij} x_j \iff A \mathbf{x} = \lambda \mathbf{x}$$
Рассчитывается итерационным методом **степенных итераций (Power Iteration)** для максимального собственного значения матрицы смежности $A$.

### 4. Степенная центральность (Degree Centrality)
Локальное число непосредственных связей узла в анализируемом графе:
$$C_D(v) = \deg(v)$$

## 7. Установка и запуск

### Требования
* Python 3.10+
* Установленные зависимости из `requirements.txt`

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Запуск основного пайплайна (Офлайн-режим по умолчанию)
```bash
python main.py
```
Скрипт загружает сохраненный граф `data/graph.pkl`, рассчитывает метрики, выводит форматированную таблицу в терминал, сохраняет `data/centrality.csv`, `reports/centrality_report.json`, `reports/graph_summary.json` и генерирует изображения в папку `reports/`.

### Запуск с обновлением данных из VK API (Онлайн-режим)
```bash
# Установите VK_TOKEN в окружение или укажите в config.py
python main.py --fetch
```

### Быстрый запуск автономных скриптов визуализации
```bash
python plot_graph.py
python plot_from_csv.py
```

### Запуск автоматических тестов
```bash
python -m unittest discover -s tests -v
```
Все 6 тестов проверяют контракты сохраненного графа, инварианты центральностей, логику 2-шагового BFS с мокированием API и корректность рендеринга.

### Запуск Jupyter Notebook
```bash
jupyter notebook notebook.ipynb
```
*(Все ячейки уже содержат предрассчитанные результаты, таблицы и интерактивные графики).*
