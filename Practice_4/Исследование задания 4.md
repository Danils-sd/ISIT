## 1. Что требует задание

В пяти стаканах находится разное количество компота. Необходимо обучить агента выравнивать объёмы, поднимая стаканы минимальное число раз. Если агент держит один стакан и разливает из него в несколько других, это считается одним поднятием.

Перед программированием нужно определить правила среды. Обязательный результат эксперимента — кривая обучения: зависимость награды агента от номера эпизода.

В PDF не заданы вместимость стаканов, точность измерения, начальные объёмы, алгоритм обучения и функция награды. Решения ниже — наши допущения для простой учебной реализации, а не дополнительные требования преподавателя. Обучение с подкреплением выбрано по смыслу постановки: агент, награда, эпизоды обучения.

## 2. Ответы на вопросы перед программированием

| Вопрос | Принятое решение |
| --- | --- |
| Сколько стаканов? | Пять, как в задании. |
| Какова вместимость? | Каждый стакан вмещает 4 условные порции. |
| Сколько всего компота? | 10 порций; при равенстве в каждом стакане будет 2. |
| Как измеряется объём? | Целыми порциями от 0 до 4, без погрешности. |
| Что агент знает? | Объёмы всех стаканов и номер стакана в руке. |
| Как выполняется переливание? | За один шаг переливается одна порция из выбранного источника в выбранный приёмник. |
| Можно ли продолжить разливать из поднятого стакана? | Да, в том числе в другие стаканы; нового поднятия при этом нет. |
| Что происходит при смене источника? | Предыдущий стакан ставится на стол, новый поднимается. Это одно дополнительное поднятие. |
| Нужно ли поднимать приёмник? | Нет, он стоит на столе. В руке одновременно один стакан. |
| Допустимы ли потери, переполнение и внешняя ёмкость? | Нет. Компот перемещается только между пятью стаканами. |
| Когда достигнут успех? | Объёмы стали `[2, 2, 2, 2, 2]`. |
| Когда прерывается неудачная попытка? | После 200 переливаний. |
| Какие начальные состояния используются? | Все пятёрки целых чисел от 0 до 4 с суммой 10. В начале руки свободны. |
| Как проверять обучение? | Без случайных действий на всех допустимых начальных распределениях. |

Дискретизация позволяет обойтись небольшой Q-таблицей. Для увеличения масштаба можно изменить константы, но обучение на других вместимостях и общих объёмах не входит в эту версию.

## 3. Состояние, действия и эпизод

Состояние — кортеж `(v1, v2, v3, v4, v5, held)`. Первые пять значений — объёмы, последнее — индекс источника в руке: от 0 до 4 или `-1`, если ни один стакан ещё не поднят.

Действие `(i, j)` означает переливание одной порции из стакана `i` в стакан `j`. Оно допустимо, если `i != j`, источник непустой, а приёмник не заполнен. Проверяются только физические ограничения: агенту разрешены и невыгодные переливания, иначе часть решения будет заранее заложена в правила.

После действия:

- объём источника уменьшается на 1, объём приёмника увеличивается на 1;
- если `held != i`, счётчик поднятий увеличивается на 1;
- `held` становится равным `i`.

Держать пустой стакан допустимо; следующее действие из другого источника всё равно потребует нового поднятия. При завершении ставить стакан на стол отдельно не требуется: это не поднятие.

Один эпизод — попытка выровнять одно начальное распределение. При успехе или достижении предела шагов эпизод заканчивается. Уже равное распределение считается решённым без действий и поднятий.

Допустимых распределений объёма 381, из них 380 требуют действий. Вместе с шестью вариантами `held` получается верхняя оценка 2286 состояний. Не все такие сочетания достижимы, но и эта оценка достаточно мала для табличного метода.

## 4. Простой алгоритм обучения

Использовать Q-learning. Таблица `Q[state][action]` хранит оценку полезности действия в состоянии. Для хранения достаточно обычного словаря Python; нейросеть и NumPy не нужны.

Во время обучения агент с вероятностью `epsilon` выбирает случайное допустимое действие, иначе — действие с максимальной Q-оценкой. Равные максимальные оценки при обучении разрешаются случайно. После переливания обновляется одна запись:

```text
Q(s, a) = Q(s, a) + alpha * (r + gamma * max Q(s_next, a_next) - Q(s, a))
```

Максимум берётся только по допустимым следующим действиям. При успехе или прекращении эпизода по лимиту будущая оценка равна нулю. Для воспроизводимости фиксируется seed генератора случайных чисел.

## 5. Награда и оптимизируемая цель

Предлагаемая награда за шаг:

```text
r = -1, если потребовалось поднять стакан, иначе 0
r -= 0.001 за переливание
r += 10 при достижении равных объёмов
r -= 10 при исчерпании лимита без успеха
```

Составляющие складываются в одну награду. При успехе на последнем разрешённом шаге штраф за неудачу не применяется.

Использовать `gamma = 1.0`, чтобы не обесценивать будущие поднятия. Суммарная награда успешного эпизода:

```text
10 - число_поднятий - 0.001 * число_переливаний
```

При лимите 200 шагов штраф за все переливания не превышает 0.2. Поэтому среди успешных решений выигрыш одного поднятия важнее любой разницы в числе переливаний. Малый штраф за шаг нужен, чтобы не поощрять бесполезные циклы. Проверка оптимальности проводится по числу поднятий отдельно от награды.

## 6. Как определить настоящий минимум

Для принятых правил минимум равен числу стаканов, где начальный объём больше 2:

```text
optimal_lifts = sum(volume > 2 for volume in initial_volumes)
```

Обоснование:

1. Каждый стакан с избытком необходимо хотя бы один раз поднять: иначе его объём не уменьшится.
2. Каждый такой стакан достаточно поднять один раз и распределить весь его избыток по стаканам с недостатком, не опуская источник между переливаниями.
3. Общий избыток равен общему недостатку. Приёмники можно наполнять ровно до цели, поэтому вместимость не нарушается.

Пример:

```text
Начало:                           [4, 3, 2, 1, 0]
Первый стакан -> четвёртый:        [3, 3, 2, 2, 0]  поднятий: 1
Первый стакан -> пятый:            [2, 3, 2, 2, 1]  поднятий: 1
Второй стакан -> пятый:            [2, 2, 2, 2, 2]  поднятий: 2
```

Формула используется только для проверки. Выбор действий обученного агента должен выполняться по Q-таблице. Подмена обучения готовым распределением излишков не выполняет смысл требования «научить агента».

## 7. Какие результаты нужно получить

- Реальное обучение на разных начальных распределениях.
- График суммарной награды по эпизодам с исходными значениями и скользящим средним.
- Проверка всех 380 неравных начальных распределений без случайного исследования.
- Доля успешных решений и доля решений с минимальным числом поднятий; обе доли считать от всех 380 случаев.
- Несколько пошаговых примеров с объёмами и счётчиком поднятий.
- Краткое описание допущений и запуска.

Кривая обучения может колебаться: меняются начальные распределения и сохраняются исследовательские действия. Рост среднего вознаграждения сам по себе не доказывает оптимальность; для этого нужна отдельная проверка по точному минимуму.
